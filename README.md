# Project Name

AdventureWorks Sample Web App.

## Features

This App connects to the sample database Adventure Works - converted from SQL Server to Azure Cosmos DB NoSQL using GitHub Copilot and Cosmos Agent Kit Skills (https://github.com/AzureCosmosDB/cosmosdb-agent-kit).

## Demo

This app is used as part of DEMO for RDBMS to Azure Cosmos DB NoSQL migration and modernisation.
